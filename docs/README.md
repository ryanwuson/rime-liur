# 蝦米輸入方案（桌面版）

基於 Rime 輸入法引擎的嘸蝦米輸入方案，支援 macOS 鼠鬚管與 Windows 小狼毫。除了標準蝦米字碼，還內建造詞、同音選字、注音／拼音、符號與變體、快打、計算機等功能。

## 功能速覽

- **基本輸入**：蝦米字碼、英文詞庫、造詞、同音選字
- **注音與拼音**：讀音查詢、蝦米內注音／拼音、獨立注音輸入法、獨立拼音輸入法
- **符號與變體**：符號清單、字母變體、變體英數、擴充模式與日期時間
- **效率功能**：快打／強制快打、萬用查字、查碼模式、計算機、Emoji

## 兩種版本

| 版本 | 說明 |
|------|------|
| **基礎版**（純中文） | 不含英文詞庫，英文需輸入完整後按 `Enter` 上屏 |
| **完整版**（含英文詞庫） | 內建英文詞庫，支援自動補全與大小寫轉換 |

詳見 [安裝需求與版本差異](/getting-started/requirements.md)。
