# 快捷鍵總表

## 方案切換（絕對跳轉）

| 快捷鍵 | 跳到 |
|--------|------|
| `Ctrl + '` | 嘸蝦米 |
| `Ctrl + Shift + '` | 注音輸入法 |
| `Ctrl + ;` | Easy English（英文） |
| `Ctrl + Shift + ;` | 拼音輸入法 |
| <code>Ctrl + &#96;</code> | 叫出方案選單 |

## 模式開關

| 快捷鍵 | 功能 | 狀態 |
|--------|------|------|
| `Shift` 或 `Caps Lock` | 中英切換 | 中文 ↔ 英文 |
| `Shift + Space` | 全半形切換 | 半形 ↔ 全形 |
| `Ctrl + /` | 查碼模式 | 正常 ↔ 查碼 |
| `Ctrl + .` | 繁簡切換 | 繁體 ↔ 简体 |
| `Ctrl + ,` | 擴充字集 | 常用 ↔ 擴充字集 |
| `,,sp` | 快打提示 | 正常 ↔ 快打提示 |
| `,,sf` | 強制快打 | 正常 ↔ 強制快打 |
| `,,wc` | 萬用查字 | 正常 ↔ 萬用查字 |
| `Ctrl + =` | 計算機 | 四套方案均可使用 |

## 翻頁

| 按鍵 | 功能 |
|------|------|
| `Tab` | 向下翻頁 |
| `Shift + Tab` | 向上翻頁 |
| `Shift + ↑` | 向上翻頁 |
| `Shift + ↓` | 向下翻頁 |
| `,`／`.` | **不是**翻頁（蝦米碼，例如 `s.`＝？、`..`＝：） |

## 選字

| 按鍵 | 功能 |
|------|------|
| `0` ~ `4` | 選對應編號的候選字（預設每頁 5 個；改成 7／9 見 [自訂設定](/getting-started/customize.md)） |
| 數字小鍵盤 `0` ~ `4` | 選對應編號的候選字 |
| `Space` | 選第一個候選字 |
| `Enter` | 將字碼或英文直接上屏 |
| `'` | 選中候選字後按 `'`，顯示同音字及字碼 |

## 造詞

| 按鍵 | 功能 |
|------|------|
| `Ctrl + K` | 刪除游標所在的臨時造詞（macOS 也可 `Fn + Shift + Delete`） |

?> **與舊版差異**：`Ctrl + '` 由「查碼」改為「切嘸蝦米」；`Ctrl + /` 由「切英文」改為「查碼」；切英文改用 `Ctrl + ;`。詳見 [方案切換與快捷鍵](/getting-started/switch-schemes.md)。
