# 手動安裝

若不想用指令，也可以自己把檔案放進 Rime 使用者資料夾。

## 步驟

1. 下載本專案所有檔案。
2. 複製到 Rime 使用者資料夾：
   - macOS：`~/Library/Rime/`
   - Windows：`%AppData%\Rime\`
3. 選擇版本：
   - **基礎版（純中文）**：從 `configs` 資料夾複製 `liur.chinese-only.schema.yaml`，改名為 `liur.schema.yaml` 放到 Rime 使用者資料夾。
   - **完整版（含英文詞庫）**：從 `configs` 資料夾複製 `liur.schema.yaml` 到 Rime 使用者資料夾。
4. **重新部署 Rime**：
   - macOS：<code>Ctrl + Option + &#96;</code>
   - Windows：右鍵點輸入法圖示 → 「重新部署」

## 字體

為確保候選字框顯示正常，請一併安裝 `fonts` 資料夾中的字體，詳見 [主題與字體設定](/appearance/theme-font.md)。
