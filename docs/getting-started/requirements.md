# 安裝需求與版本差異

## 安裝需求

| 平台 | 輸入法前端 | 下載 |
|------|-----------|------|
| macOS | 鼠鬚管 Squirrel | [下載頁](https://github.com/rime/squirrel/releases) |
| Windows | 小狼毫 Weasel | [下載頁](https://github.com/rime/weasel/releases) |

請先安裝對應平台的 Rime 前端，再安裝本方案。

## 版本差異

| 版本 | 說明 |
|------|------|
| **基礎版**（純中文） | 不含英文詞庫；英文需輸入完整後按 `Enter` 上屏 |
| **完整版**（含英文詞庫） | 內建英文詞庫，支援英文自動補全與大小寫轉換 |

- 兩版都可中英混輸，差別只在「英文是否有詞庫候選」。
- 指令安裝時可於過程中選擇版本；手動安裝則對應不同的 `liur.schema.yaml`，詳見 [手動安裝](/getting-started/install-manual.md)。
