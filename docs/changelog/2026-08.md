# 2026-08 版本更新說明

## 方案與切換

- 新增兩套 **獨立方案**：[注音輸入法](/features/bopomofo.md)、[拼音輸入法](/features/pinyin.md)，適合長時間用注音／拼音打字。
- 切換快捷鍵全面調整：
  - `Ctrl + '`：切回嘸蝦米
  - `Ctrl + Shift + '`：注音輸入法
  - `Ctrl + ;`：Easy English（英文）
  - `Ctrl + Shift + ;`：拼音輸入法
  - `Ctrl + /`：查碼模式（原為切英文）
  - 詳見 [方案切換與快捷鍵](/getting-started/switch-schemes.md)。
- [自訂設定](/getting-started/customize.md)：候選字每頁幾個、快打／強制快打常駐要改哪個檔。

## 新功能

- [計算機](/features/calculator.md)：四套方案均可按 `Ctrl + =`；嘸蝦米另可直接輸入 `,,=`。
- [符號清單](/features/symbols.md)與 [擴充模式](/features/extended.md)（<code>&#96;</code>／<code>&#96;&#96;</code>）：注音、拼音已與 Easy English 對齊，四套方案皆可使用。
- [Emoji](/features/emoji.md)：注音／拼音輸入時隨附 Emoji 候選。
- [強制快打](/features/quick-mode.md)：`,,sf`，直接以簡碼出字。

## 字庫與讀音

- **讀音依據**（詳見 [讀音查詢與蝦米內注音／拼音](/features/phonetic-lookup.md)）：
  - 繁體：教育部《重編國語辭典修訂本》，並參考教育部《異體字字典》
  - 簡體：《新華字典》
- **同音字補漏**：已補足缺漏；例如「康」可找到「鱇」。詳見 [同音選字](/features/homophone.md)。
- **簡、繁字碼表拆分**：快打／強制快打的簡碼提示依簡繁模式分開（例：簡體「髮」可提示 `fx`，繁體則無）。詳見 [快打與強制快打](/features/quick-mode.md)。
