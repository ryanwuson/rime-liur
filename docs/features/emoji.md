# Emoji

輸入注音／拼音時，候選會隨附對應的 Emoji，讓你直接選用。

## 觸發方式

| 情境 | 觸發 |
|------|------|
| 嘸蝦米方案內（行內） | 用 [蝦米內注音輸入](/features/phonetic-lookup.md#蝦米內注音輸入) `';` 或 [蝦米內拼音輸入](/features/phonetic-lookup.md#蝦米內拼音輸入) `;'` 時，候選隨附 Emoji |
| 獨立注音輸入法 | 直接輸入時隨附 Emoji |
| 獨立拼音輸入法 | 直接輸入時隨附 Emoji |

![Emoji](../images/17.Emoji.gif)

## 說明

- Emoji 以獨立候選附加，不會改寫原本的中文候選。
- 主力嘸蝦米字碼輸入不加 Emoji，只在注音／拼音的音碼段生效。
