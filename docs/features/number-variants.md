# 變體英數

以 `` ` `` 加上不同符號引導，輸入各種變體英文字母與數字。

## 變體Aa（首字母大寫）

- **引導鍵**：<code>&#96;/</code>
- **提示**：《變體Aa》
- **說明**：用 `.` 分隔單字，每個單字首字母大寫，可連續輸入。
- **舉例**：<code>&#96;/hello.world</code> → Ⓗⓔⓛⓛⓞ Ⓦⓞⓡⓛⓓ

![變體Aa](../images/07.1.1變體Aa.gif)

## 變體aa（全小寫）

- **引導鍵**：<code>&#96;//</code>
- **提示**：《變體aa》
- **舉例**：<code>&#96;//hello.world</code> → ⓗⓔⓛⓛⓞ ⓦⓞⓡⓛⓓ

![變體aa](../images/07.1.2變體aa.gif)

## 變體AA（全大寫）

- **引導鍵**：<code>&#96;///</code>
- **提示**：《變體AA》
- **舉例**：<code>&#96;///hello.word</code> → ⒽⒺⓁⓁⓄ ⓌⓄⓇⓁⒹ

![變體AA](../images/07.1.3變體AA.gif)

## 變體數字 — 連打

- **引導鍵**：<code>&#96;/'</code>
- **提示**：《變體數字》
- **說明**：用 `.` 分隔數字；若要用數字鍵選字，於結尾按 `'`。
- **舉例**：<code>&#96;/'123</code> → ①②③

![變體數字連打](../images/07.2變體數字連打.gif)

## 變體數字 — 單選

- **引導鍵**：<code>&#96;'</code>
- **提示**：<code>&#96;'</code>《變體數字》
- **範圍**：<code>&#96;'00</code> ~ <code>&#96;'50</code>
- **舉例**：<code>&#96;'01</code> → ① ⓵ ⑴ ⒈ 🄂 １ ₁ ¹ 𝟏 𝟙 𝟷 𝟣 𝟭 Ⅰ ⅰ ㊀ ㈠ …

![變體數字單選](../images/07.3變體數字單選.gif)
