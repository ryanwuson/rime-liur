# 同音選字

## 功能說明

- **操作**：選中候選字後按 `'`。
- **說明**：顯示該字的同音字及其字碼，方便查找同音異字。
- **注意**：簡體模式下亦可對應相關同音字，如「发」的同音字有「伐」「瞂」「法」。
- **補足缺漏**：已補足同音字缺漏；例如打「康」後按 `'`，可找到「鱇」等字。

## 應用場景

- 忘記某個同音字的編碼時，可透過已知的字查找。
- 快速輸入同音異字，不必重新輸入編碼。

## 使用範例

輸入 `ld` 選中「勵」後按 `'`，會出現同音字列表：

- 力 〔勵〕⟨DX⟩ ⟨DY⟩
- 立 〔勵〕⟨LE⟩
- 利 〔勵〕⟨HRI⟩
- ……

打「康」後按 `'`，亦可找到「鱇」等同音字。
