# 字母變體

以 `` ` `` 引導，輸入各種花式字母。嘸蝦米、注音、拼音、Easy English 皆可。與 [變體英數](/features/number-variants.md) 搭配可組出完整的裝飾字。

## 圈圈／方框等字母變體

- **輸入**：<code>&#96;a</code> ~ <code>&#96;z</code>
- **提示**：<code>&#96;</code>《變體a》
- **說明**：切換圈圈字母、方框字母、雙線字母、哥德體等。
- **舉例**：<code>&#96;a</code> → Ⓐ ⓐ 🅐 🄰 🅰 …
