# 蝦米字碼輸入

- 直接輸入蝦米字碼，按 `Space` 或數字鍵即可選字上屏。
- 輸入像 `www.google.com` 這類內容時，按 `Enter` 可將原始英文直接上屏。

![基本輸入](../images/02.1基本輸入.gif)

## 選字操作

| 按鍵 | 功能 |
|------|------|
| `Space` | 選第一個候選字 |
| `0` ~ `4` | 選對應編號的候選字（預設每頁 5 個） |
| 數字小鍵盤 `0` ~ `4` | 選對應編號的候選字 |
| `Enter` | 將輸入的字碼或英文直接上屏 |
| `'` | 選中候選字後按 `'`，顯示同音字（見 [同音選字](/features/homophone.md)） |

?> 預設每頁 5 個候選。若要改成 7 或 9，見 [自訂設定](/getting-started/customize.md)。

## 翻頁

| 按鍵 | 功能 |
|------|------|
| `Tab` | 向下翻頁 |
| `Shift + Tab` | 向上翻頁 |
| `Shift + ↑` | 向上翻頁 |
| `Shift + ↓` | 向下翻頁 |
