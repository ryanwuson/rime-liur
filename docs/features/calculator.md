# 計算機

在輸入法內直接算式運算，結果可當候選字上屏。

## 使用方式

- **四套方案通用**：按 `Ctrl + =` 叫出計算機。
- **嘸蝦米方案另可使用**：直接輸入 `,,=`。
- 輸入算式後，候選會顯示計算結果，按數字或 `Space` 上屏。

### 範例

| 輸入 | 結果 |
|:-----|:-----|
| `,,=1+2*3` | 7 |
| `,,=(8-3)/2` | 2.5 |

## 各方案的操作方式

| 方案 | 操作方式 |
|------|----------|
| 嘸蝦米 | `Ctrl + =`，或直接輸入 `,,=` |
| 注音輸入法 | `Ctrl + =` |
| 拼音輸入法 | `Ctrl + =` |
| Easy English | `Ctrl + =` |
