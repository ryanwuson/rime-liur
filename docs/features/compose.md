# 造詞

## 臨時造詞

臨時造詞適合日常使用，造詞後可立即使用，系統會自動儲存。

### 操作方式

1. 輸入 `;` 進入造詞模式（顯示《造詞》▸）。
2. 依序輸入每個字的編碼，用 `` ` `` 分隔。
3. 按 `Space` 確認上屏。

### 使用範例

- **造「臺北車站」**：`` ;te`ffl`cj`lzo `` → 臺北車站
- **造「行政院」**：`` ;mv`ezp`br `` → 行政院

![造詞功能](../images/03.造詞功能.gif)

### 刪除臨時造詞

打出造詞後，游標移到該詞條，按 `Ctrl + K`（macOS 也可用 `Fn + Shift + Delete`）即可刪除。

### 臨時造詞編碼規則

造詞後會自動產生 4 碼快捷編碼，取每個字的「首碼」組合：

| 詞長 | 編碼規則 | 說明 |
|:----:|:--------:|:-----|
| 2 字詞 | ABBB | 第1字首碼 + 第2字首碼×3 |
| 3 字詞 | ABCC | 第1字首碼 + 第2字首碼 + 第3字首碼×2 |
| 4 字以上 | ABCZ | 第1字首碼 + 第2字首碼 + 第3字首碼 + 末字首碼 |

| 詞彙 | 各字首碼 | 造詞編碼 |
|:----:|:---------|:--------:|
| 台北 | 台(u) 北(f) | `ufff` |
| 行政院 | 行(m) 政(e) 院(b) | `mebb` |
| 台北市政府 | 台(u) 北(f) 市(l) 政(e) 府(l) | `ufll` |

### 儲存位置

| 平台 | 位置 |
|:----:|:-----|
| macOS | `~/Library/Rime/liur.userdb/` |
| Windows | `%AppData%\Rime\liur.userdb\` |

?> 分享方案給他人時，請勿包含 `liur.userdb/`，以免洩漏個人造詞。

## 直接編輯造詞

需要批量新增或與他人分享詞庫時，可直接編輯詞庫檔。

### 步驟

1. 開啟 `openxiami_CustomWord.dict.yaml`。
2. 新增詞條（格式：`詞彙<Tab>編碼`），不受臨時造詞編碼規則限制。
3. 儲存後 **重新部署 Rime**（macOS：<code>Ctrl + Option + &#96;</code>；Windows：右鍵圖示 →「重新部署」）。

### 詞條格式範例

```yaml
嘸蝦米	liu
```

### 檔案位置

| 平台 | 路徑 |
|:----:|:-----|
| macOS | `~/Library/Rime/openxiami_CustomWord.dict.yaml` |
| Windows | `%AppData%\Rime\openxiami_CustomWord.dict.yaml` |

?> 直接編輯詞庫必須重新部署才生效；此檔可備份，換機時直接沿用。
