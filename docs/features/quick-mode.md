# 快打與強制快打

## 快打模式（簡碼提示）

- **開關**：`,,sp`（輸入後按空格）
- **狀態**：正常 ↔ 快打提示
- **說明**：開啟後會在候選字旁提示可用的簡碼，幫助你學習並記住常用字的簡碼。

### 提示格式

- `簡碼▸⟨x⟩`：表示該字可用字碼 `x` 輸入，顯示在候選字的註解區。

| 輸入 | 候選字 | 簡碼提示 |
|:----:|:------:|:---------|
| `ttmb` | 頂 | ▸簡碼⟨TTA⟩ |
| `lonm` | 毫 | ▸簡碼⟨LVM⟩⟨LNM⟩ |

![快打模式](../images/09.快打模式.gif)

### 注意事項

- 快打提示主要用於學習簡碼，熟悉後可關閉以減少視覺干擾。
- 可與 [查碼模式](/features/code-view.md) 同時使用。
- **簡、繁字碼表已拆開**：簡碼提示依 **簡體／繁體** 模式分開，提示會更正確。
  - 例：簡體「髮」`vax` 可提示 `fx`（发）；繁體「髮」則無此簡碼提示。

## 強制快打

- **開關**：`,,sf`（輸入後按空格）
- **狀態**：正常 ↔ 強制快打
- **說明**：比「快打提示」更進一步限制使用者非以簡碼輸入無法輸出候選字，當「提示簡碼且按空白鍵無法上屏」時，請再次輸入「簡碼+空白鍵」即可輸出候選字，無法按 Esc 鍵清碼。
- 簡碼提示同樣依 **簡體／繁體** 模式分開。

![強制快打](../images/09.2強制快打.gif)

?> 「快打提示」只是提示簡碼，按空白鍵仍可輸出候選字；「強制快打」必須依照提示之簡碼再次輸入。兩者可依習慣擇一使用。

### 若需常駐

`,,sp`、`,,sf` 預設每次部署後會關閉。若要重新部署後仍常開，改 `liur.schema.yaml` 裡對應開關的 `reset`，見 [自訂設定](/getting-started/customize.md)。
