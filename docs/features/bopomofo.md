# 注音輸入法（獨立方案）

這是一套 **獨立的注音方案**（`liu_bpmf`），適合長時間用注音打字。與嘸蝦米方案裡的 [蝦米內注音輸入](/features/phonetic-lookup.md#蝦米內注音輸入) 不同，這裡是完整的注音輸入體驗。

## 切換到注音

- **快捷鍵**：`Ctrl + Shift + '`
- 切回嘸蝦米：`Ctrl + '`
- 也可用 <code>Ctrl + &#96;</code>（反引號）叫出方案選單選「注音輸入法」。

## 基本操作

| 按鍵 | 功能 |
|------|------|
| 注音鍵位 | 依鍵盤注音佈局輸入 |
| `Space` | **一聲**（不必另打聲調）；有候選時＝選字上屏 |
| `Enter` | 中文上屏 |
| `\` | 手動分節。例如「西岸」打成 `ㄒㄧ･ㄢ`；若不分節，會連成 `ㄒㄧㄢ`，變成「現」 |

![注音輸入法](../images/13.注音輸入法.gif)

## 注音文

**Shift + Enter**：以**注音文**上屏（直接輸出注音符號本身，例如 ㄊㄧˇ）。

![注音文](../images/13.2注音文.gif)

## 分節

音節黏成別的字時，按 `\` 手動切開。例如「西岸」應打成 `ㄒㄧ･ㄢ`；若不分節，會連成 `ㄒㄧㄢ`，變成「現」。（與蝦米內注音相同）

![注音分節](../images/13.3注音分節.gif)

## 常用標點

大千鍵盤上 `,` `.` `;` `/` 是注音鍵，標點用 Shift／旁鍵：

| 按鍵 | 輸出 |
|------|------|
| `Shift + ,` / `Shift + .` | ， 。 |
| `Shift + /` / `Shift + 1` | ？ ！ |
| `Shift + ;` / `Shift + '` | ： 、 |
| `"` | ； |
| `[` `]` | 「 」 |
| `{` `}` | 『 』 |

組字中按 `[` `]` 仍為選詞首字／末字；無組字時才輸出引號。

## 說明

- 空白鍵直接當一聲，二三四聲照鍵盤聲調鍵輸入。
- 可連續輸入多字再一次上屏。
- 只打每個字的**首碼**也可組詞，例如 `ㄅ ㄓ ㄉ` →「不知道」。
- 單字候選會附上蝦米字碼，方便一邊打注音、一邊學拆碼；詞組不提示。
- 支援繁簡、Emoji 隨附（見 [Emoji](/features/emoji.md)）。
- 與 Easy English 相同，可直接用 [符號清單](/features/symbols.md)（<code>&#96;</code>）與 [擴充模式](/features/extended.md)（<code>&#96;&#96;</code>）。組字中按 <code>&#96;</code> 仍是一聲備援，請先清空再叫出符號清單。
