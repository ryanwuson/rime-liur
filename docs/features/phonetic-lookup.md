# 讀音查詢與蝦米內注音／拼音

以下功能都在 **嘸蝦米方案內** 以引導鍵觸發，用來查讀音，或用注音／拼音找中文。若你想長時間用注音／拼音打字，請改用獨立的 [注音輸入法](/features/bopomofo.md) 或 [拼音輸入法](/features/pinyin.md)。

## 讀音依據

讀音依目前的繁簡模式切換：

| 模式 | 依據 |
|------|------|
| 繁體 | 教育部《重編國語辭典修訂本》，並參考教育部《異體字字典》的音讀 |
| 簡體 | 《新華字典》 |

影響範圍包含 `;;` 讀音查詢，以及蝦米內注音／拼音顯示的讀音。

## 讀音查詢

- **引導鍵**：`;;`
- **提示**：《讀音查詢》▸
- **說明**：輸入字碼，顯示讀音。
- **舉例**：`;;ohe` → 國 {ㄍㄨㄛˊ}

![讀音查詢](../images/05.1讀音查詢.gif)

## 蝦米內注音直出

- **引導鍵**：`';'`
- **提示**：《注音直出》▸
- **說明**：輸入注音符號，可連續輸入；若需一聲符號，可按 2 次 `''`（也可不輸入）。
- **舉例**：`';'wu3s/65''2u0''` → ㄊㄧˇㄋㄥˊㄓˉㄉㄧㄢˉ

![注音直出](../images/05.2注音直出.gif)

## 蝦米內注音輸入

- **引導鍵**：`';`
- **提示**：《注音輸入》▸
- **說明**：在嘸蝦米方案內以注音找中文，可連續輸入。
- **舉例**：`';1upzpu,204j06w961o3` → 繽紛耶誕玩台北
- **手動分節**：按 `\`。例如「西岸」應打成 `ㄒㄧ ⁞ ㄢ`；若不分節，會連成 `ㄒㄧㄢ`，變成「現」。

![注音輸入](../images/05.3注音輸入.gif)

![注音分節](../images/05.5注音分節.gif)

## 蝦米內拼音輸入

- **引導鍵**：`;'`
- **提示**：《拼音輸入》▸
- **說明**：在嘸蝦米方案內以漢語拼音找中文，支援數字 1~5 鍵入聲調，可連續輸入。
- **舉例**：`;'binfenye2danwan2taibei` → 繽紛耶誕玩台北
- **手動分節**：按 `\`。例如「西岸」應打成 `xi ⁞ an`；若不分節，會連成 `xian`，變成「現」。
