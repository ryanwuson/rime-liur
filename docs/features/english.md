# 英文輸入與英文詞庫

## 英文輸入模式（Easy English）

- **快捷鍵**：`Ctrl + ;`
- **說明**：切換到英文連續輸入方案，內建豐富詞組，輸入完成後按 `Space` 上屏。
- 要切回嘸蝦米按 `Ctrl + '`。

![英文輸入](../images/02.2英文輸入.gif)

## 英文詞庫輸入（完整版限定）

在完整版（含英文詞庫）中，英文單字會直接出現在候選選單：

- **自動補全**：輸入 `app` 會在候選顯示 `apple`、`application` 等。
- **空白上屏**：選好英文單字後按 `Space` 上屏。
- **大小寫轉換**：
  - 輸入英文後按 `]` → 首字母大寫（`word` → `Word`）
  - 輸入英文後按 `]]` → 全部大寫（`word` → `WORD`）

![英文詞庫](../images/02.3英文詞庫.gif)
