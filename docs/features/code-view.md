# 查碼模式

## 功能說明

- **開關**：`Ctrl + /`
- **狀態**：正常 ↔ 查碼
- **說明**：開啟後會在候選字旁顯示該字的字碼，方便學習與查詢。

## 功能特色

1. **字碼顯示**：每個候選字旁顯示對應字碼。
2. **學習輔助**：幫助你學習不熟悉的字的拆碼方式。
3. **反查功能**：在一般輸入、簡體、造詞、蝦米內注音輸入等情境均可使用，支援多字同時查詢字碼。

## 提示格式

- `~⟨編碼⟩`：顯示該字的字碼（`~` 表示反查結果），顯示在候選字的註解區。

| 輸入 | 候選字 | 字碼顯示 |
|:----:|:------:|:---------|
| `ohe` | 國 | ~⟨OHE⟩ ⟨OKA⟩ ⟨OAQE⟩ |
| `';su3` | 你 | ~⟨PNS⟩ |

## 注意事項

- 查碼模式主要用於學習字碼。
- 可與 [快打模式](/features/quick-mode.md) 同時使用。
- 搭配 [蝦米內注音輸入](/features/phonetic-lookup.md#蝦米內注音輸入) 可查不會拆的字。
