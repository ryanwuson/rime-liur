# 擴充模式與日期時間

以雙反引號 <code>&#96;&#96;</code> 進入擴充模式，可輸出日期時間、帶音調字母等。嘸蝦米、注音輸入法、拼音輸入法、Easy English 皆可使用。

## 擴充模式選單

- **引導鍵**：<code>&#96;&#96;</code>
- **提示**：<code>&#96;&#96;</code>▸
- **顯示**：日期時間〔/〕、小寫變化〔a~z〕、大寫變化〔A~Z〕

<img src="../images/08.1擴充模式選單.png" alt="擴充模式選單" style="zoom:50%;" />

## 日期時間選單

- **輸入**：<code>&#96;&#96;/</code>
- **提示**：《日期時間》▸
- **說明**：以多種格式輸出當下的年、月、日、時、分。

![日期選單](../images/08.1日期選單.png)

## 日期時間分類

- **輸入**：<code>&#96;&#96;/01</code> ~ <code>&#96;&#96;/10</code>

| 分類 | 範例 |
|:----:|:-----|
| [01]時間 | 17:30:45、17:30、17時30分45秒、下午5:30:45 … |
| [02]日期 | 2025/12/03、2025-12-03、星期三、週三 … |
| [03]中文 | 2025年12月3日、二零二五年十二月三日 … |
| [04]民國 | 民國114年12月3日 … |
| [05]日本 | 令和7年12月3日 … |
| [06]英文 | December 3, 2025、Wednesday … |
| [07]農曆 | 農曆十一月初三、乙巳年丁亥月癸卯日 … |
| [08]組合 | 2025/12/03 17:30、2025年12月3日 星期三 … |
| [09]時區 | UTC+08:00、CST … |
| [10]節氣 | 小雪、大雪 … |

- **舉例**：<code>&#96;&#96;08</code> → 組合

![日期時間舉例](../images/08.1舉例.gif)

## 字母變化形

### 小寫字母變化形

- **輸入**：<code>&#96;&#96;a</code> ~ <code>&#96;&#96;z</code>
- **提示**：《a變化》
- **舉例**：<code>&#96;&#96;a</code> → ā á ǎ à â ä ã å …

![小寫字母變化形](../images/08.2小寫字母變化形.gif)

### 大寫字母變化形

- **輸入**：<code>&#96;&#96;A</code> ~ <code>&#96;&#96;Z</code>（Shift+字母）
- **提示**：《A變化》
- **舉例**：<code>&#96;&#96;A</code> → Ā Á Ǎ À Â Ä Ã Å …

![大寫字母變化形](../images/08.3大寫字母變化形.gif)
