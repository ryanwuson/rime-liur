# 萬用查字

## 功能說明

- **開關**：`,,wc`（輸入後按空格）
- **符號**：`?`（Shift + /）
- **狀態**：正常 ↔ 萬用查字
- **說明**：支援 3~4 碼字，最多 2 個 `?`。

## 使用範例

| 類型 | 輸入 | 說明 |
|:----:|:----:|:-----|
| 3 碼字 | `ab?` | 查 ab 開頭的 3 碼字 |
| 3 碼字 | `a?c` | 查 a_c 格式的 3 碼字 |
| 3 碼字 | `a??` | 查 a 開頭的 3 碼字 |
| 4 碼字 | `abc?` | 查 abc 開頭的 4 碼字 |
| 4 碼字 | `a??d` | 查 a__d 格式的 4 碼字 |
